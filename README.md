# NovaCare Hospital: Clinical Operations & Capacity Audit

## 🏥 Project Overview
This repository contains a full-stack healthcare analytics project investigating a systemic throughput crisis at **NovaCare Hospital**. I analyzed 5,000 clinical records to identify the root causes of ambulance diversions and ward overcrowding.

## 📂 Repository Structure
The project is organized into 5 distinct phases to reflect the analytical lifecycle:

1. **`Business_Context`**: The "Genesis" of the project, containing the initial clinical complaints and raw source files (`Patients.xlsx`, `Admissions.xlsx`).
2. **`Excel_Data_Audit`**: Documentation of the initial data cleaning, validation, and the definition of the 10 core healthcare KPIs.
3. **`SQL_Analysis`**: Advanced relational queries and result sheets used to uncover hidden patterns like the "Sunday Surge" and "Rehab Bottlenecks".
4. **`PowerBI_Strategic_Dashboard`**: The technical core of the project, featuring the `.pbix` file and the high-fidelity "Capacity & Surge Command Center".
5. **`Executive_Storytelling`**: The "Cure" for the hospital's problems, featuring the final executive summary and the strategic roadmap for leadership.

## 🔍 Key Clinical Insights
* **The Sunday Surge:** Admission volume peaks every Sunday at **737 admissions**, testing hospital capacity limits right before the Monday shift starts.
* **The Boarding Crisis:** The Pediatric Ward is severely misaligned, with **714 adults** (Average age: **46.10**) currently "boarding" in specialty beds.
* **Efficiency Gap:** Urgent admissions require a significantly longer stay (**4.27 days**) than emergency or elective cases, primarily due to chronic adult conditions like UTI and Diabetes.
* **Discharge Stasis:** Flow is paralyzed by **252 seniors** medically cleared for discharge but "stuck" awaiting Rehabilitation placement.

## 💡 Strategic Roadmap
* **Bed Leveling:** Reallocate 15-20% of Pediatric bed capacity to a dedicated "Adult Overflow" unit to resolve the 4.26-day delay.
* **Surge Staffing:** Implement a 15% staffing increase on Sundays and Mondays to manage the 737-patient peak.
* **Fast-Track Rehab:** Prioritize insurance pre-authorization for seniors to clear the 252-patient discharge bottleneck.
